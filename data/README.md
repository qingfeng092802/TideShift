# `data/` 数据来源与口径

> 这个目录里的东西**不是同一类数据**，混在一起看会得出错误结论。逐文件说明如下。
> 一句话版本：**电价有出处，负荷与气温是合成的**。

## 1. `price_yuan_per_kwh` —— 有正式文件出处

**来源**：广东省发展改革委《关于进一步完善我省峰谷分时电价政策有关问题的通知》
（**粤发改价格〔2021〕331 号**，2021-08-31 发布）。

原文与本仓库实现的对应关系：

| 文件原文 | 本仓库实现 |
|---|---|
| 高峰时段为 10-12 点、14-19 点 | `PRICE_PERIODS["高峰"].range = [(10,12),(14,19)]` |
| 低谷时段为 0-8 点 | `PRICE_PERIODS["低谷"].range = [(0,8)]` |
| 其余时段为平段 | `[(8,10),(12,14),(19,24)]` |
| 尖峰电价执行时间为 **7 月、8 月和 9 月**三个整月 | `PRICE_PERIODS["尖峰"].months = (7,8,9)` |
| 尖峰每天执行时段为 11-12 时、15-17 时共三个小时 | `[(11,12),(15,17)]` |
| 尖峰在高峰电价基础上**上浮 25%** | `spike_price = peak_price × 1.25` |
| 峰 : 平 : 谷 = **1.7 : 1 : 0.38** | `peak = flat × 1.7`，`valley = flat × 0.38` |

时段划分的**唯一实现**是 `src/data/data_generator.py::PRICE_PERIODS`；
四个价格值由 `src/utils/config.py::PriceConfig` 按上面的比例推导，不是手填：

```
平段基准 0.65  →  高峰 1.105  →  尖峰 1.38125
             ↘  低谷 0.247
```

**必须知道的限制**：

- **0.65 元/kWh 是示例平段基准价，不是任何一户的实际到户电价。** 实际到户价含
  上网电价/代理购电价、输配电价、基金及附加，各月、各电压等级、珠三角与粤东西北都不同，
  且 2023 年后工商业目录销售电价已逐步被代理购电价格表取代。
  本仓库只保证**比例关系与时段划分**符合 331 号文，不保证绝对价格等于某张电费单。
- 尖峰 1.38125 **刻意不取整**：取整后 `尖峰 / 高峰` 就不再严格等于 1.25，
  比例一致性测试也会失败。
- 331 号文的适用范围是**工商业用户**（大工业及一般工商业）；居民另行规定，本仓库不涉及。
- 政策会变。改动前先查现行文件，改 `PRICE_PERIODS` 与 `PriceConfig` 后
  **必须把 `backend/server.py::PRICE_RULE_VERSION` +1**，否则磁盘上的旧求解缓存
  会顶着旧日历的价格被命中，症状是"改了代码但数字没变"。

## 2. `load_kw` —— 合成

`src/data/data_generator.py::generate_load_profile`，按"典型工商业日负荷形状 ×
温度修正"生成，基准 1500 kW（`LoadConfig.base_load_kw`），`seed=42` 可复现。
**不是真实计量数据**，不可用于生产结算或容量规划。

## 3. `ambient_temp_c` —— 合成

`generate_ambient_temp`：月度基准 + 日变化正弦 + 噪声。
它只是热模型的**环境边界条件示例**，既不是气象站观测气温，更不是电池箱体进风温度或电芯温度。
用真实气象数据替换是后续工作。

## 4. `dr_signals.csv` —— 离线示例，不在 Web 链路上

Web 流程按所选调度日自动生成两个默认 DR 事件（15:00-17:00 / 11:00-12:00，
均落在 331 号文的尖峰窗口内），
并支持页面手工触发与 `POST /api/dr/trigger`。
本 CSV 只被测试与命令行寻优脚本（`--with-dr`）引用，**改它不会改变界面上的 DR 事件**。

## 重新生成

```bash
python -c "from src.data.data_generator import generate_all_data; generate_all_data()"
```

`seed=42`，输出 `data/load/load_data.csv`、`data/price/typical_price.csv`、
`data/battery/battery_params.csv`。
